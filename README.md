MyBank Pro
MyBank Pro — вебзастосунок для керування рахунком і карткою, переказів між користувачами та перегляду фінансових операцій. Застосунок створено на Django з використанням SQLite та адаптивного вебінтерфейсу українською мовою.
Можливості
- Реєстрація користувачів та вхід до облікового запису.
- Персональний рахунок і віртуальна платіжна картка.
- Перегляд балансу та основної інформації про картку.
- Поповнення рахунку.
- Перекази між користувачами системи.
- Історія операцій із пошуком і фільтрацією.
- Збереження отримувачів.
- Сповіщення про операції.
- Блокування та розблокування картки.
- Сторінка профілю.
- Адміністративна панель Django для керування даними.
- Адаптивний інтерфейс для різних розмірів екрана.

Встановлення та запуск
Потрібен встановлений Python 3.12 або новіший, сумісний із версією Django у requirements.txt.
1. Розпакуйте архів і відкрийте термінал у папці mybank_pro.
2. Створіть і активуйте віртуальне середовище:
python -m venv .venv
.venv\Scripts\Activate.ps1


3. Встановіть залежності:
python -m pip install -r requirements.txt


4. Створіть міграції та застосуйте їх до бази даних:
python manage.py makemigrations banking
python manage.py migrate


5. За потреби створіть адміністративний обліковий запис:
python manage.py createsuperuser


6. Запустіть сервер:
python manage.py runserver


Відкрийте застосунок у браузері: http://127.0.0.1:8000/

Адміністративна панель доступна за адресою: http://127.0.0.1:8000/admin/
Структура проєкту
- bank/ — налаштування Django та головні маршрути.
- banking/ — моделі даних, представлення, маршрути та адміністративна панель.
- templates/ — HTML-шаблони сторінок.
- static/ — стилі та JavaScript.
- manage.py — утиліта керування Django.
- requirements.txt — залежності проєкту.
Примітка щодо операцій
Картки та фінансові операції створюються всередині MyBank Pro. Поповнення й перекази змінюють баланс у локальній базі даних; інтеграція з банками або зовнішніми платіжними сервісами не налаштована.
